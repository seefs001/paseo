# 定时任务 {#schedules}

定时任务按 cron 节奏运行工作。默认使用指定的提示词和 Agent 设置启动新的 Agent，项目可选，也可以[只在工作台创建迷雾任务，不启动 Agent](/docs/schedules-cli#file-board-tasks)。

Paseo 还有 **heartbeat**。heartbeat 会定期向一个已有的 Agent 发送提示词，让它重新评估并继续同一段对话。

两者使用同一个 cron 引擎，但在产品中是分开的：

- **定时任务**每次运行可以新建 Agent、继续指定对话或创建看板任务。你可以查看、暂停、恢复、运行一次、更新或删除它们。
- **heartbeat** 针对一个已有的 Agent，刻意保持轻量：通过 MCP 创建或删除；在 CLI 中还可以只更新它们的 cron 周期。

cron 是标准的节奏表示。CLI 接受 `5m` 或 `1h` 这样的简单预设，但会把它们编译成 cron，而不是另存一种间隔类型。

两者都按你设定的节奏运行。如果想由外部事件（比如一条评论或一次提及）启动 Agent，请参见 [Hub](/docs/hub)。

## 用途 {#what-its-for}

- **全新的周期性任务**：为每日分拣、报告或维护启动一个干净的 Agent。
- **heartbeat**：让当前 Agent 定期重新评估状态并继续推进。
- **盯构建**：让一个 Agent 持续检查 CI、EAS、Docker 或发布构建，直到通过。
- **每日分拣**：每天早上扫描 issue、PR 和失败的检查。
- **维护巡检**：更新依赖、审核文档或清理过期分支。

## 创建方式 {#ways-to-create-one}

- **在应用中**：打开定时任务视图，设置 Agent、cron 节奏和提示词来创建，项目可选。这是创建和管理定时任务的主要方式。
- **[在聊天中](/docs/schedules-chat)**：在聊天中告诉 Agent，它会为你创建定时任务。
- **[通过 CLI](/docs/schedules-cli)**：`paseo schedule create`，适用于无界面的机器和脚本。
- **[通过 MCP](/docs/mcp)**：Agent 以编程方式创建和管理定时任务。

## 选择工作区和对话 {#choose-a-workspace-and-conversation}

在应用的计划视图中创建或编辑计划。工作区和对话都可不选：

- **都不选**：每次按 Agent 设置新建工作区及对话。可以选择项目，也可以选择“无项目”，在主机用户的主目录运行，工作区不归属任何项目。“无项目”使用本地隔离，需要更新主机。
- **只选工作区**：每次在该工作区新建对话，不另建工作区。
- **选择工作区和对话**：每次向同一对话发送提示词，沿用它当前的模型和运行模式。表单不再显示新 Agent 设置。

对话列表只显示所选主机、所选工作区中的可用对话。切换或清空工作区会清除对话选择。如果目标选择不可用，请更新主机。

指向已有对话的计划仍支持修改提示词、暂停、运行一次和查看日志。对话忙碌时，本次运行记为失败，不中断其工作；后续仍按 cron 执行。服务端拒绝已归档、已删除或不匹配的目标。运行发现目标失效时，会在日志中记录原因并结束计划。归档目标对话也会结束指向它的计划。

## 选择角色 {#choose-a-role}

新建对话的计划可以在“角色”中选择主机上的角色，用它的指令创建 Agent。“无角色”不添加角色指令。角色关联的默认 Agent profile 会填入 Agent 设置，保存前仍可修改。Provider 不支持单个 Agent 的 system prompt 时，需更换 Provider 或移除角色。

计划会保存角色名称和指令。之后修改角色不会改变已保存的计划；要使用新指令，重新选择角色并保存。指向已有对话的计划沿用该对话的角色，不显示此字段。

## 保留运行工作区 {#keep-run-workspaces}

未选择已有工作区时，新建 Agent 的定时任务每次运行都会创建一个工作区。**Archive on finish** 默认开启：运行结束时，Paseo 会归档该工作区及其 Agent。使用 worktree 隔离时，最后一个使用该 worktree 的活跃工作区被归档后，归档还会删除这个 worktree。

要保留运行结果，在应用的定时任务视图中打开该定时任务，关闭 **Archive on finish** 并保存。Paseo 会让每次运行的工作区和 Agent 保持活跃，直到你手动归档；在创建 Agent 之前就失败的运行仍会被清理。该选项同样适用于本地隔离；归档本地工作区不会删除项目目录。

存储的选项是 `target.config.archiveOnFinish`，一个布尔值，省略时默认为 `true`。CLI 和 MCP 的定时任务工具不提供这个选项；请在应用中修改。指向已有工作区的计划不会归档该工作区及其中的对话，运行失败或删除计划也不会清理它们。此时表单隐藏自动归档选项。heartbeat 同样不会自动清理工作区。
